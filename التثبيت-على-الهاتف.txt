تثبيت تطبيق لمعة الاعتقاد على الهاتف
================================
1. لا تفتح ملف index.html مباشرة من الملفات (file://) ولا من صفحة GitHub العادية؛ التثبيت يتطلب رابط HTTPS.
2. ارفع مجلد التطبيق كما هو إلى استضافة HTTPS، الأسهل:
   - GitHub Pages: أنشئ مستودعا وارفع كل الملفات إلى جذره، ثم Settings > Pages > Deploy from branch (main / root)، وافتح رابط https://USERNAME.github.io/REPO/
   - أو Netlify Drop: اسحب المجلد إلى app.netlify.com/drop
3. افتح رابط HTTPS من متصفح Chrome على الهاتف وانتظر تحميل الدروس مرة واحدة (للتخزين دون إنترنت).
4. في Chrome: القائمة ⋮ > تثبيت التطبيق / Add to Home screen > تثبيت. وفي iPhone (Safari): مشاركة > إضافة إلى الشاشة الرئيسية.
5. ملاحظات:
   - الفيديوهات تحتاج إنترنت؛ باقي الدروس والاختبارات تعمل دونها.
   - بعد أي تحديث جديد افتح الرابط مرة واحدة أونلاين لتحديث الكاش (الآن v3).
   - إن ظهر خطأ في GitHub تأكد أن الرابط المفتوح هو رابط Pages وليس github.com/.../blob/...
